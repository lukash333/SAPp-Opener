This is simple input application, especially for SAP users.
 
Depends on the input length, user can open SAP system:
  - system ID : e.g. "S1P"
  - language + system ID: e.g. "enS1P"
  - language + system ID + client: e.g. "enS1P100"
 
Additional commands are also available and you can add them in config.ini file
For now running exe apps is supported and webpages.
 
Requirements:
- Python Installed
 
To easy run main.py without command prompt, you can create *.bat file like that:
 
start /b pythonw "YourPath\main.py"
